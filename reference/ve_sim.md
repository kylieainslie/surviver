# Simulated ground-truth data for time-varying vaccine effectiveness

Two scenarios simulated with the
[HERMES](https://github.com/lwillem/ibm_hermes) individual-based model
in which the true vaccine effectiveness as a function of time since
vaccination, VE(t), is known. Both use the same synthetic population of
10,000 people, a 180-day epidemic, and a rolling vaccination campaign
(16 ten-day rounds from day 21, each vaccinating 3% of the remaining
eligible population). They differ only in the VE curve:

## Usage

``` r
ve_sim_waning

ve_sim_no_waning
```

## Format

Each is a list with elements:

- demographic:

  Data frame, one row per individual: `ind_id`, `age`, `sex`, `hh_id`,
  `classroom_id`, `workplace_id`.

- vaccination:

  Data frame, one row per vaccinated individual: `ind_id`,
  `time_of_vaccination` (study day).

- incidence:

  Data frame, one row per reported case: `ind_id`, `time_of_reporting`
  (study day; includes a reporting delay, so can exceed `study_end`).
  Only symptomatic cases (80% of infections) are reported, and 10% of
  those are missed.

- params:

  List of HERMES parameters used. The true VE(t) is defined by
  `vaccine_effectiveness` (peak), `ve_ramp_days`, `ve_half_life` and
  `ve_floor`.

- study_end:

  Length of the study in days (180).

- hermes_commit:

  Commit of `ibm_hermes` that generated the data.

An object of class `list` of length 6.

An object of class `list` of length 6.

## Source

HERMES by Lander Willem (<https://github.com/lwillem/ibm_hermes>; [user
manual](https://github.com/lwillem/ibm_hermes/blob/lorentz_center_workshop/doc/user_manual_HERMES.pdf)),
with the waning-VE extension on the [`waning-vaccine-effectiveness`
branch](https://github.com/kylieainslie/ibm_hermes/tree/waning-vaccine-effectiveness).
Generated by `data-raw/ve_test_scenarios.R`.

## Details

- `ve_sim_waning`: VE rises linearly to 0.8 over 14 days, then decays
  exponentially (half-life 45 days) towards a floor of 0.1.

- `ve_sim_no_waning`: VE rises linearly to 0.8 over 14 days, then stays
  at 0.8.

The two runs are not paired realisations of one epidemic: transmission
is random and diverges between them from the start.

HERMES vaccinates people regardless of infection status, so some
vaccinated people were infected before vaccination. Those reported soon
after vaccination should be censored; see
[`reported_soon_after_vaccination()`](https://kylieainslie.github.io/surviver/reference/reported_soon_after_vaccination.md).
